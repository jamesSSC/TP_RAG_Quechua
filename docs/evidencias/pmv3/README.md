# Evidencias del PMV3

Evidencias de desarrollo del PMV3, con la convención `<ID>_<entorno>_<qué_se_ve>.png`. El reporte que
las ordena está en `docs/18_REPORTE_PMV3.md` y la cronología, en `BITACORA.md`.

| Carpeta | Contenido |
|---|---|
| `movil/` | Capturas del emulador (en línea, modo avión, selector, letra máxima, 429), salidas de `flutter test`, `flutter analyze`, del arnés de 248 consultas en el dispositivo, de la paridad del índice y de las mediciones (arranque, memoria, APK). Cada `.txt` tiene su `.png` legible al imprimirlo |
| `nube/` | Estado de la API desplegada tras la limpieza de Neon (H-14) |
| `local/` | (reservada para la web local) |

Las capturas no muestran secretos: la app no lleva tokens y no se capturó ninguna consola de Render ni
de Neon.

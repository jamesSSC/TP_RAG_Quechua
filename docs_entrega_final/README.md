# Entrega final del proyecto

Material que piden las guías del docente para la U4 y la entrega final: métricas, pruebas con
usuarios, video, insumos del informe y del artículo, cifras oficiales, Kanban, ICACIT, logo y póster.
La guía pide `./docs`; se usó `./docs_entrega_final` para no mezclarla con la documentación SDD de
`docs/` (lo mismo que en la S13 con `docs_auditoria/`).

El índice de todo, ordenado según la estructura del informe, está en
`RESPUESTA_AGENTE_PMV3_ENTREGA_FINAL.md`.
